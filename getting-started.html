GETTING STARTED.

Everything you need to know before joining Beyond SMP.

🚧 Server not live yet: Beyond SMP is still in development. play.beyond-smp.com is the planned server IP, but it is not joinable yet and will not lead to the live server until launch.

Requirements

  • Minecraft Java Edition
  • Minecraft version 1.21.1
  • The Beyond SMP modpack
  • A linked Minecraft and Discord account

Joining the Server

  1. Open Minecraft Java Edition and go to Multiplayer.
  2. Select Add Server.
  3. Set the name to Beyond SMP.
  4. Use play.beyond-smp.com as the server address.
  5. Join the server.

Discord Verification

Go to discord.beyond-smp.com and link your accounts using Simple Discord Link.

  1. Join the Minecraft server.
  2. If your Minecraft and Discord accounts are not linked, you will be kicked.
  3. The kick screen gives you a verification code.
  4. In Discord, run /verify [code].
  5. Rejoin the Minecraft server.

Modpacks

Beyond SMP provides two modpacks so players do not need to download 50+ individual mods.

  • Beyond SMP - Essential: essential mods only; recommended for lower-tier PCs.
  • Beyond SMP - Enhanced: Essential plus extra quality-of-life features and shaders; recommended for mid-to-high-end PCs. It includes multiple shader options for different hardware levels.

The packs are distributed through Modrinth. The Modrinth organisation can be reached through Discord, with mod.beyond-smp.com planned as a convenient redirect.

First Steps

At the start of each season, players enter the spawn selection area. This is a one-time seasonal selection process where you choose your faction and your path within that faction. The selection area is not the normal spawn and is only available at the beginning of each season.

Once your choices are made, you cannot normally change faction during the season. If you make a genuine mistake, contact staff; a faction change may be considered case-by-case.

Paradis Paths

Players choosing Paradis select either Cadet or Citizen. Citizens follow the civilian life of Paradis, while Cadets train toward a military branch.
