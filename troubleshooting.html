OFFICIAL BEYOND SMP HELP CENTRE

TROUBLESHOOTING.

Beyond SMP has not launched yet, so many real-world issues are still unknown. These are the main problems currently expected.

Wrong Minecraft Version

Beyond SMP is planned for Java Edition 1.21.1. Make sure your launcher is running the required version.

Modpack Not Fully Updated

Make sure your Beyond SMP modpack is fully updated. Mixing old and new versions can cause connection or mod-loading problems.

Wrong Modpack

Choose the pack that matches your PC. Essential is recommended for lower-tier PCs. Enhanced adds extra quality-of-life features and shaders and is intended for mid-to-high-end PCs.

Cannot Verify Discord

If you are kicked for not being linked, use the code on your kick screen with /verify [code] in the official Discord, then rejoin.

Still Having Problems?

Contact staff through the official Discord and open a support ticket. You can also use the Help Centre at help.beyond-smp.com.
