MODS & MODPACK.

Server Version

Minecraft: Java Edition 1.21.1

Mod loader: Fabric.

Official Modpacks

  • Beyond SMP - Essential: essential mods only; recommended for lower-tier PCs.
  • Beyond SMP - Enhanced: Essential plus extra quality-of-life features and shaders; recommended for mid-to-high-end PCs.

The packs contain the required mods so players do not need to manually install 50+ mods.

Installing

Get the appropriate pack from Modrinth, then use its install/get option and launch it through the Modrinth app.

The Modrinth organisation can be reached through the Discord link, with mod.beyond-smp.com intended as a convenient redirect.

Which Pack?

Essential: choose this if you have a lower-tier PC or want the lighter setup.

Enhanced: choose this if you have a mid-to-high-end PC and want the extra quality-of-life features and shaders.

Common Problems

  • Using the wrong Minecraft version.
  • Using a modpack that has not been fully updated.
  • Choosing the Enhanced pack on a lower-end PC.

If you still have a problem, use the Help Centre or open a ticket in the Discord server.
