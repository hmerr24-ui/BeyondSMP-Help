MODS & MODPACK.

Beyond SMP uses a Fabric-based modpack so players can install the server's required mods without downloading them individually.

Versions

  • Minecraft: 1.21.1
  • Server: Java Edition
  • Modpack environment: Fabric 1.21.1

Beyond SMP - Essential

Contains only the essential mods needed for the intended server experience. Recommended for lower-tier PCs.

Beyond SMP - Enhanced

Contains everything in Essential plus extra quality-of-life features and optional shaders. Recommended for mid-to-high-end PCs. Multiple shader options are planned for different performance levels.

Installation

The packs are distributed through Modrinth. Open the pack through a compatible Modrinth-capable launcher, press its install/get option and then launch/play the instance.

Other launchers should work if they support Modrinth mods and modpacks. Beyond SMP is not currently planned around CurseForge distribution.

What You Need

The required mods are included in the modpacks. No separate resource pack is currently required. Shaders are optional and manually enabled.

Updates

Keep your installed modpack fully updated. Using an outdated pack or mixing the wrong pack/version can prevent you from joining.
